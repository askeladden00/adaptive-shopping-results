Evaluation suite

41 hand-labeled shopper queries: a 26-case dev set (including out-of-scope, prompt-injection, no-result and multi-turn cases) and a 15-case held-out set written after the rules and prompt were frozen. Each case is scored on intent accuracy against a gold label and on five guardrails that must hold on every page. The release gate decides SHIP or HOLD for the selected engine: guardrails on every case, intent accuracy on the held-out set. Gemini runs are paced for free-tier keys (about 8 calls a minute, waiting out rate limits), so a full run takes roughly 15 to 25 minutes.
